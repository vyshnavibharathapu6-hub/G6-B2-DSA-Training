# Singly Linked List — Practice Questions

**Training Group:** G6-B2  
**Language:** Python  
**Topic:** Data Structures and Algorithms (DSA)

## Q01. Music Playlist Manager
**Problem:** Build a menu-driven music playlist application using a singly linked list.

**Operations:**
- Insert at beginning, end, and specified position
- Delete at beginning, end, and specified position
- Search for a song
- Count songs
- Display playlist
- Reverse playlist
- Exit using a menu-driven program with `match-case`

**File:** `Q01_Music_Playlist_Manager.py`

## Q02. Student Record Manager
**Problem:** Build a student record application using a singly linked list.

**Operations:**
- Register students at beginning, end, and specified position
- Delete and search students using ID
- Display all student records
- Count students
- Find student(s) with the highest marks
- Reverse registration order

**File:** `Q02_Student_Record_Manager.py`
